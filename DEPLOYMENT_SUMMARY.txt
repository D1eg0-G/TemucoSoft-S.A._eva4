⚡ QUICK START (5 MINUTOS):

Paso 1: Crear 2 instancias t2.micro en AWS Console
   - Image: Ubuntu 22.04 LTS
   - Type: t2.micro
   - Security Group: abierto a 80, 443, 8000-8003, 22

Paso 2: SSH a Backend
   $ ssh -i ~/key.pem ubuntu@BACKEND_IP
   $ curl -O https://raw.githubusercontent.com/D1eg0-G/TemucoSoft-S.A._eva4/main/deploy-backend.sh
   $ bash deploy-backend.sh

Paso 3: SSH a Frontend
   $ ssh -i ~/key.pem ubuntu@FRONTEND_IP
   $ curl -O https://raw.githubusercontent.com/D1eg0-G/TemucoSoft-S.A._eva4/main/deploy-frontend.sh
   $ bash deploy-frontend.sh
   (Ingresa IP del backend cuando se solicite)

Paso 4: Acceder
   Frontend: http://FRONTEND_IP
   Backend:  http://BACKEND_IP/api/master

📞 SOPORTE:

Problema: No conecta al backend
Solución:
  1. Verificar security groups (80, 8000-8003 abiertos)
  2. $ curl http://BACKEND_IP:8000 (testa puerto directo)
  3. $ sudo supervisorctl status (ver si Django está corriendo)

Problema: Django no arranca
Solución:
  1. $ tail -f /var/log/supervisor/temucosoft-master.err.log
  2. Ver credenciales .env (BD)
  3. $ python manage.py migrate (comprobar migraciones)

Problema: Frontend no carga
Solución:
  1. $ sudo tail -f /var/log/nginx/error.log
  2. $ sudo nginx -t (test configuración)
  3. $ ls -la /var/www/html (verificar archivos)
